# Naming Brief

## What the name must communicate

The product is a personal, sovereign context and evidence system—not a cloud note silo, chat bot,
team knowledge base, or cryptocurrency wallet. The name should support a native desktop product,
CLI, local service, open export format, and optional private repository.

## Criteria

Score candidates on:

1. trademark and domain clearance;
2. distinctiveness in software, AI, security, and knowledge management;
3. pronunciation and spelling;
4. absence of misleading security promises;
5. suitability for a local-first personal context platform;
6. package, bundle ID, binary, schema, and protocol migration cost;
7. international and accessibility review;
8. repository and license continuity.

## Constraints

- “MindVault” remains a working name until clearance.
- A rename must not rewrite Git history or obscure the public Apache-2.0 boundary.
- Internal stable identifiers and schema formats should not change solely for branding.
- DevX, Meridian, CodePark, and DevX Runtime names remain separate.
- Avoid “vault” if the product cannot substantiate the implied security posture.

## Decision process

Shortlist three candidates only after legal/domain/package screening. Run user comprehension tests,
select the most reversible migration, publish an alias/deprecation map, and preserve old export
readers and repository attribution.

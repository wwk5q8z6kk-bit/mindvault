# Bottom-Up Market and Value Model

**Date:** 2026-07-31 · All sizing **H** unless noted

## Customer value equation (primary ICP)

```text
Value/user/month
≈ 4–10 hrs context reconstruction avoided × fully loaded $/hr
+ 1–2 avoided high-severity agent mistakes / quarter (amortized)
+ displaced overlapping AI-memory/search spend
− migration/training
− model/compute pass-through
− review burden
```

**Illustrative base (H):** 6 hrs/month × $100/hr = $600 labor value; price $79/user → strong ROI if retention holds.

# Category Design and Positioning

**Date:** 2026-07-31

**Category:** Trusted Human–Agent Work System  
**Platform end-state:** Sovereign Context Fabric

**Problem statement:** Organizations can generate AI activity, but cannot complete accountable work with owned context, explicit authority, and evidence.

**Why existing categories fail:** Notes lack agency; chat lacks permanence; tickets lack context authority; gateways lack work semantics and personal vault ownership.

**Why now:** Agent deployment + MCP surfaces + standards pressure on identity/governance (2026).

**Comparisons buyers make:** Notion AI, Slack+agents, Linear, MCP gateways, Obsidian+plugins. Win by completing trusted work, not by feature checklist parity.

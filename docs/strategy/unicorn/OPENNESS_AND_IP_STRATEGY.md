# Openness and IP Strategy

**Date:** 2026-07-31 · Recommendations (owner approval required before license changes)

| Component | Recommendation |
|---|---|
| Applications / premium UX | Proprietary |
| Context/authority kernel | Source-available or open-core later; not permissively open day one without strategy |
| Schemas, event/receipt formats | Open specification |
| SDKs | Permissive OSS |
| Connectors | Open-core / community |
| Domain Packs (reference) | Open examples; certified packs commercial |
| MCP/A2A adapters | OSS adapters |
| Conformance suites | Open + certification product |
| Hosted/managed private | Managed service |
| Enterprise policy packs | Proprietary |
| Extension registry | Open discovery; signed trust classes |

Principle: moat = quality, trust, execution, ecosystem—not hostage data. Preserve Apache-2.0 public baseline rights already granted.

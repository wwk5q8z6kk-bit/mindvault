# Wedge Customer Journey

**Date:** 2026-07-31

1. **Trigger:** Agent incident, audit question, or founder outreach.
2. **Install:** Local MindVault node (or design-partner private deploy).
3. **Import/bind evidence:** Existing notes/nodes as source evidence.
4. **First Work Order:** Define goal, node contracts, risk Low, Engine executor.
5. **Approve / start / execute:** Human admits run; system leases; `execute` produces digested artifact.
6. **Magic moment:** User sees artifact + provenance + gate results and accepts—replacing a Slack thread + doc paste.
7. **Habit:** Weekly trusted runs become the team’s AI work log.
8. **Expansion:** More seats, more evidence sources, Spaces, then live effects under grants.
